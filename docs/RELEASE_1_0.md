# 1.0.0 — attributed source snapshot and research toolkit

The first stable release captures every identifier in the frozen BBAW / TELOTA
IG XV 1 digital source index: 593 responses retrieved, 592 parsed records, and
one malformed source response preserved unchanged in quarantine (IG XV 1, 150).

The conservative Greek subset has 170 source-interpreted records. Other parsed
records comprise 18 Eteocypriot-labelled, 7 uncertain-language and 397 unclassified
entries. These counts describe digital entries, not independent ancient objects.

Includes original XML, source and licence attribution, Unicode interoperability
inventory, deterministic extraction, conservative analytical tokens, offline
search and audit commands, JSON/CSV/TEI exports, export checksums, JSON Schema,
and a deterministic downloadable ZIP.

Validation: 21 positive/negative tests; full source replay; all 592 records checked
against the JSON Schema; export roundtrip, hashes and file membership verified.

Scope: stable software and a bounded source snapshot. Exhaustive coverage,
independent epigraphic review, object/witness deduplication, linguistic gold and
cross-script phonetic inference remain unresolved or blocked. The digital source
does not replace the printed critical edition and its apparatus. No endorsement
by the source editors or institutions is claimed.

Next: the separately scoped Eteocypriot project, then source-pinned family
cross-references. Third-party XML and adapted edition content remain CC BY 4.0;
retain NOTICE, source attribution and record-level links when reusing the data.
