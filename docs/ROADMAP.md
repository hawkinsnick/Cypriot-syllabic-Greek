# Release roadmap

## 0.1 — source admission
Frozen digital index, licence evidence, attributable acquisition and explicit units.

## 0.5 — reproducible corpus and toolkit
Unchanged primary-source XML, source replay, Greek subset classification, search,
Unicode interoperability inventory, conservative statistics and exports.

## 0.9 — release candidate
Adversarial validation tests, source reconciliation, reproducible generated files,
component licensing, release manifest and downloadable package checks.

## 1.0 — stable source snapshot and toolkit
All entries in the frozen source index accounted for and retrieved (including
explicit, unchanged source-defect quarantine), source fidelity
replay passing, tests passing, export integrity verified, documented research gates.
This milestone is not exhaustive scientific coverage or independent expert approval.

## After 1.0
The next user-requested project is Eteocypriot. Reuse primary-source identifiers
without duplicating them as independent witnesses. Add component-level language
assertions for bilingual records and compare source versions explicitly.

Then cross-reference the prior corpus projects: inspect their actual current
releases, pin source commits and hashes, and define adapters for provenance,
rights, uncertainty and sampling units. Do not pool signs or transfer sound values
across scripts. Any linguistic benchmark requires reviewed alignments, documented
train/test separation, object deduplication and suitable known-answer controls.

Longer-term Cypriot work: extend beyond this fascicle; add source-verified ICS and
museum concordances; resolve object identities; acquire authorized plate/image
references; compare independent editions; seek expert review for selected readings.
